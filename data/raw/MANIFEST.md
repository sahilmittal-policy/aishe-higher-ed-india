## Coverage

Each report contains a back-series (Tables 43-52) restating the previous
five years. Combined coverage of the five files is 2015-16 to 2023-24.

| Report | Reference years covered |
|---|---|
| 2019-20 | 2015-16 to 2019-20 |
| 2020-21 | 2016-17 to 2020-21 |
| 2021-22 | 2017-18 to 2021-22 |
| 2022-23 | 2018-19 to 2022-23 |
| 2023-24 | 2019-20 to 2023-24 |

## Not held

2018-19 and earlier are published as PDF only. Not required for the
back-series panel, which reaches 2015-16 via the 2019-20 report. Would be
needed only for response-rate tables prior to 2019-20.
